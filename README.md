### Hi, I'm Subhankar Pal

Full-stack developer working across TypeScript, Next.js, Node.js, and NestJS — I build things end to end: frontend, backend, and the infrastructure that ties them together. Open to full-time roles and freelance work.

**Featured projects**

**[Digital Wallet Ledger](https://github.com/spal45/Digital_Wallet_Ledger)** — a NestJS + PostgreSQL backend built the way real financial systems are: an append-only double-entry ledger where balances are derived, not stored, idempotent transfers, and row-level locking verified correct under real concurrent load with automated tests. Tested, containerized, CI'd on every push, and [deployed live](https://digitalwalletledger-production.up.railway.app/docs).

**[ChatApp](https://github.com/spal45/Chat_App)** — a real-time messaging platform built as a microservices system: a Next.js frontend, three independent backend services (auth, chat, mail) coordinated over MongoDB, Redis, and RabbitMQ, WebSocket messaging via Socket.IO, and a one-command Docker Compose setup.

**[3D Portfolio](https://github.com/spal45/3d-portfolio)** — a personal portfolio site built with Next.js and Framer Motion, using a scroll-driven animation sequence in place of a static one-page layout.
