**Featured project — [ChatApp](https://github.com/spal45/Chat_App)**
A real-time messaging platform built as a microservices system: a Next.js frontend, three independent backend services (auth, chat, mail) coordinated over MongoDB, Redis, and RabbitMQ, WebSocket messaging via Socket.IO, and a one-command Docker Compose setup. The README documents the architecture and the real engineering problems solved along the way.
